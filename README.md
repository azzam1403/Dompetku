# Dompetku

Aplikasi web pencatat keuangan pribadi bergaya mobile banking.

## Fitur
- Saldo tunai, e-wallet (DANA, GoPay, dll.), dan mobile banking dalam satu tempat
- Catat pemasukan, pengeluaran, dan transfer antar dompet
- Anggaran per kategori dengan indikator progres
- Laporan bulanan dengan grafik donat
- Foto struk dan tampilan struk transaksi
- Edit transaksi dan penyesuaian saldo
- Cadangkan, pulihkan, dan ekspor CSV

## Cara pakai
Buka `index.html` di browser, atau lihat versi onlinenya di GitHub Pages.

## Catatan
Semua data tersimpan di browser perangkat (localStorage), tidak dikirim ke server mana pun.
Gunakan menu **Dompet > Cadangkan & ekspor data** secara berkala.
